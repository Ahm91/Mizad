## 1. الهدف التجاري
برنامج مكتبي عربي لإدارة المبيعات والمشتريات والمخزون والذمم والصندوق للمحلات التجارية والمؤسسات الصغيرة والمتوسطة، يعمل دون إنترنت على جهاز واحد أو عدة أجهزة في شبكة محلية، ويُباع كمنتج تجاري قابل للتثبيت والصيانة والتطوير.

**معايير النجاح:** الكاشير يُتم بيعة من 5 أصناف بالباركود في أقل من 30 ثانية؛ أرصدة المخزون والذمم والصندوق تطابق الحركات دائماً؛ صاحب المحل يرى أرباحه وديونه وأرصدته بدقة يومياً؛ لا فقدان بيانات (نسخ احتياطي مُتحقق منه).

### رحلة المستخدم الرئيسية (الكاشير — UC-02)
دخول ← (فتح وردية) ← نقطة البيع (تركيز تلقائي على حقل الباركود) ← مسح الأصناف (كل مسح يضيف/يزيد) ← تعديل كمية/وحدة إن لزم ← F9 ← إدخال المبلغ المستلم ← عرض الباقي ← اعتماد ⇐ طباعة الإيصال ⇐ فاتورة فارغة جديدة جاهزة للمسح.

### تدفق البيانات بين الوحدات
```
المشتريات ──وارد بتكلفة──► المخزون ◄──صادر بالمتوسط── المبيعات
    │                        ▲   ▲                        │
    │ دائن المورد            │   └── المرتجعات/الجرد/التحويل│ مدين العميل
    ▼                        │                            ▼
 دفتر الأطراف ◄── سندات القبض والصرف ──► الصندوق ◄── الدفع عند البيع/الشراء
    │                                        │
    └────────────► التقارير ولوحة التحكم ◄───┘ (قراءة فقط، قابلة للمطابقة)
```

## 6. القيود والافتراضات
- محل واحد (عدة مخازن ممكنة)، عملة واحدة، قاعدة بيانات واحدة مشتركة.
- SQL Server Express مقبول (حد 50GB للقاعدة في إصدار 2025، و10GB في الإصدارات الأقدم).
- الماسح الضوئي للباركود يعمل كلوحة مفاتيح (Keyboard Wedge) وينهي بـ Enter.
- الطابعات الحرارية مثبتة كطابعات Windows عادية (برامج تشغيل الشركة المصنعة).
- الأجهزة في نفس المنطقة الزمنية.
