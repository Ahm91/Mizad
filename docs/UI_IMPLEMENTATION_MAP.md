### S01 — تسجيل الدخول (UI-01)
- **التخطيط:** بطاقة مركزية بزوايا 18 على خلفية فاتحة متدرجة. اليمين: لوحة كحلية `Navy850` بالشعار الفاتح، «إدارة المبيعات والمشتريات»، خط فاصل فيروزي قصير، الشعار النصي «تجارتك بوضوح، وحساباتك بثقة»، رسم توضيحي (صورة أصول — حاسوب ومخطط وصناديق وآلة حاسبة؛ يُنتج كأصل PNG خفيف أو يُبسط). اليسار: أيقونة مستخدم في مربع `Teal50`، العنوان والوصف، حقل اسم المستخدم بأيقونة، حقل كلمة المرور بقفل وعين، «تذكرني»، زر الدخول الفيروزي، ملاحظة معلومات، «الإصدار x.y».
- **السلوك:** Enter من أي حقل = دخول؛ تركيز أولي على اسم المستخدم (أو كلمة المرور إن كان الاسم متذكَّراً)؛ تحذير Caps Lock؛ رسائل: «اسم المستخدم أو كلمة المرور غير صحيحة»، «الحساب مقفل حتى hh:mm»، «الحساب معطل»؛ الزر معطل أثناء التحقق.
- **الخدمات:** `AuthService.LoginAsync`، `UserPreferencesStore`.

### S02 — الإطار (UI-02 + D-024)
- **الشريط الجانبي** بالترتيب الموحد (D-024): لوحة التحكم (home)، المبيعات (shopping-cart)، فواتير المبيعات (file-text)، المشتريات (shopping-bag)، فواتير المشتريات (files)، المرتجعات (undo-2)، الأصناف (box)، المخزون والجرد (boxes)، العملاء (users)، الموردون (truck)، الصندوق والمصروفات (wallet)، التقارير (bar-chart-3)، المستخدمون والصلاحيات (shield-check)، الإعدادات (settings).
- **الترويسة:** التاريخ بأيقونة تقويم · اسم المحل · بحث عام · جرس بعدّاد أحمر · بطاقة المستخدم (صورة رمزية، الاسم، الدور، سهم ⇐ قائمة: تغيير كلمة المرور، الوردية، تسجيل الخروج).

### S03 — لوحة التحكم (UI-02)
- 4 مؤشرات: مبيعات اليوم (أزرق، حقيبة)، أرباح اليوم التقديرية (أخضر، يتطلب `Reports.ViewProfit`)، ديون العملاء (برتقالي، «مستحق على N عميلاً»)، مشتريات اليوم (أحمر). المقارنة مع أمس بشارة نسبة.
- «اتجاه المبيعات» آخر 7 أيام: منحنى + نقطة اليوم مع تلميح.
- «إجراءات سريعة»: فاتورة بيع جديدة (Navy)، إضافة صنف (Teal)، فاتورة شراء (Outline) — حسب الصلاحيات.
- «آخر العمليات»: الوقت، العملية (أيقونة + نوع)، الرقم، الطرف، المبلغ، الحالة.
- «تنبيهات المخزون»: الصنف، الرصيد (أحمر)، الحد الأدنى، الحالة (منخفض جداً ≤ 50% من الحد / منخفض) + «عرض كل التنبيهات».

### S04 — نقطة البيع (UI-03)
- **رأس:** 3 بطاقات: رقم الفاتورة (معاينة الرقم المتوقع)، التاريخ، العميل (افتراضي «زبون نقدي»، بحث بالاسم/الهاتف، F4).
- **إدخال الأصناف:** حقل بحث كبير «ابحث بالاسم أو الباركود» بحد فيروزي + زر مسح الباركود. ماسح الباركود يعمل كلوحة مفاتيح؛ Enter بباركود مطابق يضيف/يزيد السطر فوراً؛ نص غير مطابق يفتح قائمة نتائج قابلة للتنقل بالأسهم.
- **الجدول:** الصنف (صورة مصغرة اختيارية، الاسم، الباركود)، الكمية (Stepper)، الوحدة (قائمة وحدات الصنف — تغييرها يعيد التسعير)، سعر البيع (قابل للتعديل بصلاحية)، الخصم، الإجمالي، حذف. تذييل: عدد الأصناف + «تفريغ الأصناف» (تأكيد).
- **ملخص الفاتورة (يسار):** الإجمالي، الخصم (تبديل مبلغ/نسبة)، الضريبة (يظهر فقط إن كانت مفعلة)، الإجمالي النهائي (أخضر)، طريقة الدفع (نقدي/آجل/جزئي)، **(تعديل DV-07)** للنقدي: «المبلغ المستلم» و«الباقي للعميل»؛ للجزئي: «المدفوع» و«المتبقي»؛ وسيلة الدفع (نقدي/بطاقة/تحويل) عند وجود مدفوع. أزرار: إتمام البيع (F9)، حفظ كمسودة (F8)، إلغاء (Esc). بعد النجاح: إشعار + طباعة تلقائية حسب الإعداد + فاتورة جديدة فارغة.
- **اختصارات:** F2 البحث، F4 العميل، F8 مسودة، F9 إتمام، Del حذف السطر، +/− الكمية، Ctrl+Del تفريغ، F6 الفواتير المعلقة.

### S05 — فواتير المبيعات (UI-04)
- مؤشرات للفترة المختارة مقارنة بالفترة السابقة: إجمالي الفواتير (عدد)، قيمة المبيعات، الفواتير الآجلة (نسبة من الإجمالي).
- مرشحات: بحث (رقم الفاتورة/العميل)، الفترة، حالة الفاتورة، طريقة الدفع، زر «فاتورة جديدة».
- الجدول: الرقم (فرز)، العميل، التاريخ (فرز)، الإجمالي، المدفوع، المتبقي (أحمر إن > 0)، الحالة (مكتملة/جزئية/آجلة/ملغاة)، طريقة الدفع، إجراءات (عرض، طباعة، مرتجع، المزيد: إلغاء بالعكس، نسخ إلى فاتورة جديدة). طباعة القائمة، تصدير Excel. ترقيم صفحات على الخادم.

### S07 — فاتورة شراء (UI-05)
- مسار تنقل «المشتريات › فاتورة شراء جديدة». الرأس: المورد*، تاريخ الفاتورة*، رقم فاتورة المورد، المخزن.
- إضافة صنف: بحث بالاسم/الباركود + «إضافة صنف جديد» (يفتح محرر الصنف كحوار ويعود بالصنف).
- الجدول: #، الصنف (الاسم + SKU)، الكمية، الوحدة، تكلفة الوحدة، الخصم %، الإجمالي، حذف.
- أسفل: طريقة الدفع*، المدفوع، ملاحظات؛ الملخص: إجمالي المشتريات، الخصم الإجمالي، الإجمالي بعد الخصم، المدفوع (أخضر)، المستحق (أحمر). أزرار: اعتماد الفاتورة، طباعة، حفظ كمسودة.

### S09 — الأصناف (UI-06)
- شريط: إضافة صنف، بحث، كل التصنيفات، كل الحالات. الجدول: صورة، الاسم، الباركود، التصنيف، الوحدة، سعر الشراء (يتطلب `Inventory.ViewCost`)، سعر البيع، الرصيد (أخضر/أحمر)، الحد الأدنى، الحالة (نشط/غير نشط)، قائمة إجراءات. ترقيم + حجم الصفحة + الإجمالي.
- المحرر الجانبي: صورة (تحميل)، الاسم*، الباركود* (توليد/مسح)، التصنيف*، الوحدة*، سعر الشراء*، سعر البيع*، رصيد افتتاحي، الحد الأدنى*، تعدد الوحدات (يكشف جدول الوحدات: الوحدة، المعامل، الباركود، سعر المفرد، سعر الجملة)، نشط. حفظ/إلغاء. (تعديل DV-10)

### S12 — المخزون والجرد (UI-07)
- مؤشرات: عدد الأصناف، قيمة المخزون (`Inventory.ViewCost`)، أصناف منخفضة، أصناف راكدة.
- مرشحات: بحث (اسم، كود، باركود)، المخزن، التصنيف، الحالة، تصفية متقدمة؛ إجراءات: طباعة، تصدير، «عمليات المخزون» (تسوية، جرد جديد، تحويل، أرصدة افتتاحية)، إضافة صنف.
- الجدول: اختيار، الصنف + الكود، التصنيف، المخزن، الرصيد الحالي، الحد الأدنى، آخر حركة (شارة النوع + التاريخ)، القيمة التقديرية، الحالة (متاح/أقل من الحد/نافد/راكد).
- «حركات الصنف» للصنف المحدد: التاريخ والوقت، النوع، الكمية ±، الرصيد بعد، المرجع، البيان.
- «تسوية مخزنية» (P13): تبويب عملية مخزنية/عملية جرد؛ الصنف*، الرصيد المسجل، الكمية المعدودة*، الفرق (ملون)، سبب التسوية*، ملاحظات، اعتماد/إلغاء.

### S15 — العملاء والديون (UI-08) و S16 — الموردون (UI-09)
- قائمة يمين: الاسم، الهاتف، الرصيد المستحق، آخر عملية، الحالة (نشط/متأخر/موقوف)؛ بحث + مرشح الحالة + إضافة.
- ملف الطرف: الاسم والحالة، الهاتف، العنوان (+ للمورد: الشخص المسؤول، البريد)؛ مؤشرات (العميل: الحد الائتماني، إجمالي المشتريات، الديون الحالية، المستحق مع «متأخر N أيام»؛ المورد: المستحق الحالي، إجمالي المشتريات، المدفوع، متوسط الفاتورة، عدد الفواتير).
- أزرار: تسجيل تحصيل/دفعة، طباعة كشف حساب. تبويبات: كشف الحساب (فترة، تصاعدي برصيد افتتاحي — DV-05)، الفواتير، الدفعات.

### S18 — الصندوق والمصروفات (UI-10)
- مؤشرات: الرصيد النقدي الحالي (حسب الحساب المختار)، إجمالي المقبوضات، إجمالي المدفوعات، مصروفات اليوم.
- أزرار: إضافة مصروف، سند صرف، سند قبض. لوحة «إضافة سند» (تبويب قبض/صرف): النوع*، المبلغ*، الجهة*، السبب*، التاريخ*، ملاحظات، حفظ/إلغاء.
- «سجل حركات الصندوق»: التاريخ، النوع (شارة)، البيان، الطرف، المبلغ ±، الرصيد بعد الحركة، الحالة؛ تصفية + تصدير.
- «أعلى فئات المصروفات»: أشرطة نسب للفترة.

### S20 — المرتجعات (مركّب من UI-13…17 — DV-12)
- تبويبان كبيران: مرتجع مبيعات / مرتجع مشتريات.
- **بيانات المرتجع:** رقم (معاينة)، التاريخ، رقم الفاتورة الأصلية* (بحث مباشر + زر يفتح لوحة «البحث عن الفاتورة الأصلية» بالفترة والعميل — UI-13/16)، الطرف (تلقائي).
- **بيانات الفاتورة الأصلية** (UI-15/17): الرقم، التاريخ، الإجمالي، المدفوع، المتبقي، الحالة، «رصيد مرتجع سابق».
- **الأسطر:** الصنف، الوحدة، المباع، المرتجع سابقاً، المتاح، كمية المرتجع (Stepper بحد المتاح)، سعر الوحدة الصافي، الإجمالي.
- **التفاصيل:** السبب*، «إعادة إلى المخزون» (UI-15)، ملاحظات، طريقة التسوية (رد نقدي / رصيد للعميل [+ اختيار فاتورة اختياري]).
- **الملخص** (UI-15): إجمالي الفاتورة الأصلية، قيمة المرتجع الحالية، المطبق على الفاتورة، المبلغ المسترد، الرصيد الجديد للفاتورة.
- **سجل المرتجعات** (UI-14): الرقم، رقم الفاتورة، الطرف، التاريخ، القيمة، الحالة (معتمد/ملغي/مسودة) + مؤشرات (العدد، إجمالي القيمة، القيمة المعتمدة).
- أزرار: اعتماد المرتجع، حفظ كمسودة، معاينة، طباعة، إلغاء.

### S21 — مركز التقارير (UI-19 أساسي — DV-14)
- يمين: «فئات التقارير» (قائمة عمودية بأيقونات): المبيعات، المشتريات، الأرباح، المخزون، العملاء والديون، الموردون، الصندوق والمصروفات، المرتجعات (+ تقارير فرعية داخل كل فئة).
- أعلى: الفترة (اليوم/الأسبوع/الشهر/السنة/مخصص — UI-24)، من/إلى، مرشحات حسب التقرير (النوع تفصيلي/ملخص، العميل، المورد، المستخدم، طريقة الدفع، التصنيف، المخزن)، «عرض التقرير»، «إعادة تعيين».
- مؤشرات حسب التقرير (مثلاً المبيعات: إجمالي المبيعات، تكلفة البضاعة، إجمالي الربح، نسبة الربح، عدد الفواتير، متوسط الفاتورة).
- رسوم: حركة يومية/أسبوعية/شهرية (منحنى أو أعمدة)، دائري حسب التصنيف أو طريقة الدفع، أشرطة الأكثر مبيعاً.
- الجدول التفصيلي بترقيم + **صف إجماليات** (UI-21) + طباعة/PDF/Excel.

### S22 — المستخدمون والصلاحيات (UI-11)
- مؤشرات: إجمالي المستخدمين، النشطون، الأدوار المعرفة. تبويبان: المستخدمون / الأدوار والصلاحيات.
- جدول المستخدمين: رقم، اسم المستخدم، الاسم الكامل، الدور (شارة ملونة بأيقونة)، الحالة، آخر دخول، إجراءات (تعديل، المزيد: تعطيل، إعادة تعيين كلمة المرور).
- الأدوار: قائمة يمين + مصفوفة صلاحيات (الوحدة × عرض/إضافة/تعديل/حذف/طباعة-تصدير) + **قسم «صلاحيات خاصة»** (DV-16) + زر إدارة الأدوار.

### S23 — الإعدادات والنسخ الاحتياطي (UI-12)
- أقسام يمين: معلومات المحل، إعدادات المبيعات، إعدادات المشتريات، العملة والتنسيقات، الطباعة والفواتير، النسخ الاحتياطي، الإعدادات العامة، الترخيص والنسخة.
- قسم النسخ: شريط الحالة (سليم/تحذير/فشل + آخر نسخة)، «سجل النسخ»، «إنشاء نسخة الآن»، «استعادة نسخة» (اختيار ملف)، «النسخ المجدول» (تفعيل، التكرار، الوقت، الاحتفاظ، المسار + استعراض، حفظ)، «معلومات النسخ» (آخر نسخة، الحجم، المسار، الحالة)، توصية مهمة.
